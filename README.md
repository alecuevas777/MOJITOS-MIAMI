# Mojitos Miami

Aplicación web para el negocio **Mojitos Miami**: coctelería y delivery en Coronel (Biobío, Chile).

**Sitio en producción:** [https://mojitosmiami.cl](https://mojitosmiami.cl)

Incluye:

- Carta digital (mojitos, cócteles, mocktails y combos)
- Carrito y pedidos por WhatsApp
- Delivery a domicilio con zonas configurables
- Servicio de barra libre para eventos
- Panel administrativo (productos, categorías, cupones, horarios, datos bancarios)


## Stack

| Parte | Tecnología |
|-------|------------|
| Frontend | React + Vite |
| API | PHP |
| Base de datos | MySQL |
| Pedidos | WhatsApp |

## Desarrollo local


```bash
npm install
npm run dev
```

- Frontend: `http://localhost:5173`
- API: `http://localhost:8000`
- Producción: `https://mojitosmiami.cl`
